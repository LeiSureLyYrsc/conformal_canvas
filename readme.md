# Conformal Canvas

# Install
```sh
sudo apt install libboost-dev libboost-url-dev libopencv-dev
git clone --recursive https://github.com/beltoforion/muparserx.git
cd muparserx && mkdir build && cd build
cmake .. && cmake --build . --config Release && sudo cmake --install . && cd ../..
```

# Build
```sh
git clone --recursive https://github.com/quqiOnfree/conformal_canvas.git
cmake .. && cmake --build . --config Release
```
